# changedetection.io — النسخة العربية التجريبية

راقب صفحات المواقع وتلقَّ إشعارًا عند تغيّر محتواها، مثل إعلان منحة جديدة أو تعديل موعد التقديم أو تغيّر السعر.

هذه نسخة مستقلة من [المشروع الأصلي](https://github.com/dgtlmoon/changedetection.io)، تحتفظ بترخيصه ونسب العمل إلى أصحابه. ليست إصدارًا رسميًا من فريق المشروع الأصلي.

## ما المتاح حاليًا؟

- 410 ترجمات من أصل 1,218 عبارة في دليل الترجمة الحالي، تشمل التنقل وأجزاء أساسية من إضافة الصفحات ومقارنة تغييراتها.
- واجهة من اليمين إلى اليسار عند اختيار العربية.
- إبقاء الروابط والبريد الإلكتروني وحقول الشيفرة من اليسار إلى اليمين.
- تحديد اتجاه نص الصفحة المراقبة تلقائيًا في المعاينة والمقارنة.
- العودة إلى الإنجليزية من قائمة اللغات.

هذه نسخة أولية وليست ترجمة كاملة. تظهر العبارات غير المترجمة بالإنجليزية، خصوصًا المساعدة والإعدادات المتقدمة. لم تُعتمد جودة التخطيط بصريًا على مختلف الشاشات بعد.

## التشغيل باستخدام Docker

ثبّت Git وDocker Desktop أولًا. افتح الطرفية وشغّل الأوامر التالية؛ على Windows يمكنك استخدام PowerShell:

</div>

```powershell
git clone --branch arabic-rtl https://github.com/HJzaz/changedetection.io.git
cd changedetection.io
docker build -t changedetection-ar .
docker run -d --name changedetection-ar --restart unless-stopped -p 127.0.0.1:5000:5000 -v changedetection-ar-data:/datastore changedetection-ar
```

<div dir="rtl">

افتح http://127.0.0.1:5000 واختر «العربية» من قائمة اللغات أعلى الصفحة. قد تُختار تلقائيًا إذا كانت لغة المتصفح العربية.

**مهم:** نبني الصورة من هذا الفرع لتضمين التعديلات العربية؛ صورة المشروع الأصلي لا تتضمن هذه التعديلات. يتوفر جلب النصوص العادي افتراضيًا؛ المواقع التي تتطلب JavaScript تحتاج إلى إعداد متصفح إضافي كما في توثيق المشروع الأصلي.

## تجربة سريعة

1. أضف رابط صفحة تريد مراقبتها من الحقل الرئيسي.
2. انتظر الفحص الأول، ثم أعد الفحص بعد تغيّر المحتوى.
3. افتح «السجل» أو «الملخص» لمقارنة اللقطات المتاحة، أو «معاينة» لقراءة اللقطة.
4. يمكن إعداد الإشعارات من قسم «الإشعارات». لا تتطلب مراقبة النصوص العادية مفتاح ذكاء اصطناعي.

## المساهمة

ملف الترجمة: `changedetectionio/translations/ar/LC_MESSAGES/messages.po`.

راجع [دليل المترجمين](changedetectionio/translations/README.md) قبل تعديل الترجمات. اترك الرموز النائبة وعلامات HTML سليمة. شغّل التجميع وفحص الترجمات والاختبارات قبل إرسال التعديلات.
